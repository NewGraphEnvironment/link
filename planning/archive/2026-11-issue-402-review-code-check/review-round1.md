## Findings

- **[severity: bug]** data-raw/wsg_species_presence_map.R:200 — `b <- b[!duplicated(b$id_barrier), ]` dedupes barriers on `id_barrier`, which is numbered per group, not globally: `fresh_default.barriers` holds `FALLS-1`, `FALLS-2`, … in every group (KLUM, UARL, BABL each run `FALLS-1`..`FALLS-9x`). Measured on local fwapg: 7,242,732 natural-barrier rows carry 140,174 distinct `id_barrier`, and 102,405 ids name more than one position. So every barrier after the first with a given id, in any other group, is silently dropped from the "Barriers behind barrier-rule records" layer, the gpkg `barriers` layer and the printed `barriers %d` count, and the popup's `id` names no unique barrier. Dedupe on `(barrier_wsg, id_barrier)` (or carry `b_blk`/`b_drm` from `pm_bar` and dedupe on position).
  - **Rule:** code-check.md "A fixture that cannot reach the failure mode" (its "Ask what an id is unique *within*, and prefer the composite key")

- **[severity: fragile]** data-raw/wsg_species_presence_map.R:119, 170, 189 — the rule layers are built from `m <- meas[meas$counting %in% TRUE, ]`, but every `data_error` record is in `excl_keys` (`.lnk_observation_exclusion_keys()` takes `data_error | release_exclude`), and `.lnk_presence_measures()` sets `counting` FALSE for any excluded key. So no known error can ever be in a rule layer: `d$known_error` is FALSE on every row and the popup's "known data error" line never prints. On the map, every known-error ring therefore sits with no rule point inside it, which reads as "the barrier and elevation rules catch none of the 67 known errors", against `recall.csv` (36 of 37 caught by the barrier rule on every barrier). The session's 216-record / 5-of-37 figures came from elsewhere, but the map, published as the tool for judging these rules (NEWS), shows the opposite of the recall. Either apply the rules to the known errors as `recall.csv` does (note their `n_class_above` excludes themselves, so the threshold is off by one there), or drop the dead flag and say in the header that the rings are never rule hits.
  - **Rule:** code-check.md "A proxy is not the property"
