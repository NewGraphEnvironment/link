## Mechanism

Every finding, in all three rounds, is a sentence about a wider population than the one its author measured. The counting records stand in for all records (Guichon's twin in round 2, MESI's second record now). The nearest barrier stands in for any barrier (round 2). The groups whose presence row changed stand in for the groups whose outputs change (the "80 groups"). The lines this branch edited stand in for every line of the edited files (round 2's token table, now the neighbouring presence row and line 96). The session's provisional call stands in for a fact about the world (the Mackenzie reason). The cells the author was thinking of stand in for the full decided set (round 2's NEWS list, now the research kept list). Each round fixed the instance a reviewer pointed at by reading the sentence's neighbours. That does not reach the next sentence whose subject is a set nobody enumerated. The enumeration below closes it for the lines this branch adds.
